## Featured Project

### TestPilot AI

**Autonomous regression testing platform combining AST-based dependency analysis, 3-layer hybrid retrieval, 11 specialized LangGraph agents, sandboxed test execution, and automated failure diagnosis.**

TestPilot AI analyzes code changes, identifies regression impact, retrieves relevant repository context, generates tests, executes them in isolated environments, diagnoses failures, and automates the review workflow.

**Stack:** Python · FastAPI · LangGraph · Tree-sitter · Qdrant · PostgreSQL · Celery · Redis · Docker · Next.js
